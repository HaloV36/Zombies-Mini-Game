# Ultimate Gun Pack — Quaternius

Source: https://quaternius.itch.io/50-lowpoly-guns

Downloaded from the author's itch.io download on 2026-09-26. License: CC0 1.0 Universal; the original License.txt is included.

These are the 40 complete OBJ guns and their MTL files, unmodified. Standalone Accessories were intentionally excluded. The runtime rotates and scales the geometry for first-person use, preserving the original shapes and material colors. The six SniperRifle models include their scopes.

Game names, stable IDs, statistics, and magnification are defined in src/game/weaponCatalog.ts. The armory page renders those same models.
